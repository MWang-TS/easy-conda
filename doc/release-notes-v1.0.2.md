# Easy Conda v1.0.2

本次为界面可读性优化版本，重点放大全局字号并修复对话框字段错位问题；同时修正开源许可声明（**Apache License 2.0**）。

## ✨ 改进

### 全局字号放大，长时阅读更友好

v1.0.1 及之前版本大量正文与表格文字使用 8–10px，在高分屏或长时间使用下阅读吃力。本次统一上调整个字号体系：

| 场景 | 原字号 | 新字号 |
|------|--------|--------|
| 正文、表格单元格、标签 | 10px | 13px |
| 次要说明、状态文字 | 9px | 12px |
| 辅助/徽标文字 | 8px | 11px |
| 主要按钮、输入框 | 11px | 14px |
| 区块标题、卡片标题 | 12–17px | 15–20px |
| 指标数字、页面主标题 | 19–27px | 21–29px |

字号放大后同步调整了胶囊标签、按钮、搜索框、实例选择器等固定高度容器的尺寸与内边距，避免文字拥挤或被裁切。

### 表格不再出现文字重叠

环境列表使用固定列宽布局，字号放大后单元格内容会互相压字。现在：

- 单元格超出宽度时按省略号截断，不再叠字
- 环境名称、Python 版本支持收缩省略，鼠标悬浮可查看完整内容
- 重新平衡列宽（环境名称 26%、Python 18%）
- 环境列表的 Python 列只显示版本号（列头已标明 "Python"），窄窗口下不再出现截断的 `Python …`

### 窄窗口布局修正

`max-width: 940px` 的响应式规则写在样式表前部，会被后续同优先级的双列基础规则覆盖，导致设置页、软件包页、帮助页在窄窗口下仍强行双列、内容挤压。现已修正为正确降级为单列。

## 🐛 修复

### 「新建环境」对话框中字段错位

对话框中带「可选」标记的字段（如下载源），标记文字会独占标签行，导致该字段的下拉框比相邻的 Python 版本下拉框低一行，视觉上不齐。

**修复**：将标签文字与「可选」标记包裹进同一行内布局容器，并让并排字段按顶部对齐，左右控件严格处于同一水平线。

### 开源许可声明错误

`README.md` 中标注为 MIT，与实际 `LICENSE` 文件（Apache License 2.0）不一致。

**修复**：更正为 **Apache License 2.0**，并在 `package.json`、`src-tauri/Cargo.toml` 中补充 `license` 字段，明确本产品（桌面应用、安装包与全部源码）均以 Apache-2.0 授权。
